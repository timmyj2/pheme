# Pheme

A local web app for agentic work on top of [GitHub Copilot CLI](https://github.com/github/copilot-cli):
chat with a session list, skills and memory that improve themselves, subagents and scheduled jobs.

> **Status:** early development. See [`PROGRESS.md`](PROGRESS.md) and the plan in [`docs/PLAN.md`](docs/PLAN.md).

## Goals

- Runs on your own machine only (`127.0.0.1`), using your existing Copilot CLI sign-in.
- Ships as one ready-to-run file: no `npm install` needed where it runs.
- Works on Windows and macOS.
